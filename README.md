# Luis Felipe Portfolio

Portfolio estatico de Luis Felipe Matias, inspirado em uma linguagem visual experimental e focado em front-end, landing pages e paginas de venda.

## Como rodar localmente

Abra `index.html` no navegador ou rode um servidor local:

```bash
python -m http.server 4173
```

Depois acesse:

```text
http://127.0.0.1:4173
```

## Deploy na Vercel

Importe este repositorio no painel da Vercel. Como o projeto e estatico, nao precisa configurar build command.
